## 배경

가상 응원석에서 아바타 머리 위 말풍선에 실시간 채팅을 노출하려 한다. 모든 원천 데이터를 그대로 노출하면 시각적 공해, 비윤리적 발언 노출, 몰입도 저하가 발생할 수 있어 명확한 정제·선별 기준이 필요하다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 4계층 분류(완전 배제 → 안전성 → 시각적 최적화 → 맥락 기반 노출) | 고품질 데이터 노출, 클린한 환경, 아바타 행동 동기화 가능성 | 실시간 필터링에 따른 미세한 레이턴시 |
| B. 무필터 노출 | 구현 없음 | 시각적 공해, 비윤리 발언 노출 |

## 결정

**A 를 채택한다.**

- 1단계 완전 배제(Hard Filter): 시스템 메시지, 플랫폼 명령어(@nightbot, /명령어 등)는 파이프라인 초기에 드롭한다.
- 2단계 안전성 확보(Safety Filter): 선수·타 팀 비하, 욕설, 혐오 표현을 차단한다.
- 3단계 시각적 최적화(Visual Refinement): 단순 감탄사(ㅋㅋㅋ, ㄷㄷ 등)는 허용하되, 도배성 긴 문장은 일정 길이로 요약하거나 아바타 이모지로 변환한다.
- 4단계 맥락 기반 노출(Contextual Priority): 경기 상황(한타 승리, 오브젝트 획득)과 연관된 키워드가 포함된 채팅을 우선 할당하고, 개인적 기도문·일상 사담은 후순위로 처리한다.

## 결과

- 좋아지는 것: 응원 분위기에 최적화된 데이터 노출, 아바타 행동(감탄사 기반)과 채팅 메시지 간 동기화 가능성 확보.
- 감수하는 것: 실시간 필터링 로직에 따른 레이턴시.
- 다시 볼 조건: 구체적 키워드 목록을 갱신할 때 (0037).
