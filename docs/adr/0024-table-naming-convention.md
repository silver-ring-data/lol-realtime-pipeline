## 결정

데이터 파이프라인 내부(Flink SQL, Athena)에서 사용하는 가상 테이블은 레이어를 직관적으로 알 수 있도록 다음 패턴을 따릅니다.

> **`{layer}_{data}_{type}`**

- **layer**: 메달리온 아키텍처 단계 (`brz`, `slv`, `gld`)
- **data**: 데이터 종류 (`chat`, `match`, `event`)
- **type**: 리소스 형태 (`strm` - 스트림 소스, `file` - S3 적재용, `rds` - DB 테이블)
