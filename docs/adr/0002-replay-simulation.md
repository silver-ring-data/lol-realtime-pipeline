# 0002. 프로 경기 데이터 수집 우회 및 시뮬레이션

> 원본: https://app.notion.com/p/3411198df8d980e19cfbdacfe0e5dd9a

| 상태 | 날짜 |
|---|---|
| 채택 | 2026-04-13 |

## 현상

- LCK와 같은 실시간 프로 경기 데이터는 일반 개발자용 Riot API로 접근이 불가능함.
- 프로젝트 시연 시 실제 경기 유무에 따른 불확실성을 제거하고, 시스템의 안정적인 부하 테스트 환경이 필요함.

## 결정

- **실시간 Replay 시뮬레이션** 방식을 채택함.
- 실제 경기에서 발생한 타임라인 JSON 데이터를 미리 확보하여, 이를 **초 단위(Real-time)로 재생**함으로써 실시간 스트리밍 레이어를 구현함.

## 이유

- **실무 적합성:** 실제 라이브 환경과 동일한 부하를 가해 파이프라인의 **가용성**을 테스트할 수 있음.
- **재현성(Reproducibility):** 동일한 대량 로그 데이터를 반복 재생하여 '민심 수치' 알고리즘의 정확도를 검증하기 용이함.
