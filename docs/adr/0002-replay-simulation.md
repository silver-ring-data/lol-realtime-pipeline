## 배경

LCK 와 같은 실시간 프로 경기 데이터는 일반 개발자용 Riot API 로 접근할 수 없다. 시연 시 실제 경기 유무에 따른 불확실성을 제거하고, 안정적인 부하 테스트 환경이 필요하다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 실시간 Replay 시뮬레이션 | 라이브와 동일한 부하로 가용성 테스트 가능, 동일 데이터 반복 재생으로 재현성 확보 | 실제 라이브 데이터는 아님 |
| B. 실제 라이브 경기 연동 | 진짜 실시간 | API 접근 불가, 시연 시점 불확실 |

## 결정

**A 를 채택한다.** 실제 경기에서 발생한 타임라인 JSON 데이터를 미리 확보하고, 이를 초 단위(Real-time)로 재생하여 실시간 스트리밍 레이어를 구현한다.

## 결과

- 좋아지는 것: 실무와 동일한 부하로 파이프라인 가용성을 테스트할 수 있고, 동일 로그를 반복 재생하여 '민심 수치' 알고리즘의 정확도를 검증하기 쉽다.
- 감수하는 것: 라이브 경기가 아닌 리플레이라는 점.
- 다시 볼 조건: 실시간 경기 API(Spectator 등)에 접근 가능해질 때.
