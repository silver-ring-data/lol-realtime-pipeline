# 0014. 분석 데이터셋 선정 및 데이터 수집 전략 확정

> 원본: https://app.notion.com/p/3441198df8d980aea634e5dfea3b9ec8

| 상태 | 날짜 |
|---|---|
| 채택 | 2026-04-16 |

## 현상

- **목표**: 초저지연 하이라이트 탐지 시스템의 성능을 증명하기 위해 대규모 트래픽과 극적인 경기 상황을 담은 실제 데이터셋이 필요함.
- **제약사항**:
  1. Riot 공식 eSports API 및 B2B 전용 API(Abios 등)는 개인 개발자가 접근하기 어렵거나 비용이 발생함.
  2. PandaScore, Oracle's Elixir 등 대중적인 API는 '초 단위(Timeline)' 데이터를 제공하지 않아 실시간 시스템 검증용으로 부적합함.
  3. SOOP(아프리카TV) 데이터 수집은 별도 API 부재로 WebSocket 리버스 엔지니어링이 필요하며, 이는 프로젝트 핵심인 '데이터 엔지니어링 파이프라인' 구축보다 수집 기술 연구에 과도한 리소스를 요구함.

## 결정

- **샘플 데이터**: **2024 롤드컵(Worlds) 결승전 (T1 vs BLG)** 데이터를 최종 선정함.
- **수집 출처**:
  1. **인게임 지표**: [GOL.GG](http://gol.gg/)의 매치 타임라인(Match Timeline) 데이터 활용 (보간법 적용)
  2. **민심 지표**: 유튜브(YouTube) 다시보기/중계의 채팅 데이터를 `pytchat` 라이브러리를 통해 추출 및 저장.

## 이유

- **상징성 및 트래픽 밀도**: 역사상 가장 높은 관심을 받은 경기로, 채팅 데이터의 폭발적인 증가(Velocity)를 테스트하기에 최적임.
- **데이터의 정밀도**: GOL.GG의 타임라인 데이터는 분/초 단위의 골드, 킬, 주요 오브젝트 발생 시점을 포함하고 있어 복잡한 윈도우 조인 로직을 검증하기에 적합함.
- **리소스 효율성**: SOOP 리버스 엔지니어링 대신 검증된 수집 도구(pytchat)를 사용하여 데이터 가공(Transformation) 및 실시간 처리 엔진(Flink) 고도화에 더 집중하기 위함.

## 트레이드오프

- **긍정적**: 유튜브 채팅의 방대한 텍스트 노이즈를 정제하는 역량을 보여줄 수 있으며, 유튜브 다시보기의 불명확한 그래프와 대비되는 **'데이터 기반 정밀 하이라이트'**의 우수성을 입증 가능함.
- **부정적**: 실제 라이브 상황이 아닌 Replay 방식이지만, 이는 시스템 구조(Architecture)상 동일하므로 엔지니어링적 가치는 훼손되지 않음.
