## 배경

초저지연 하이라이트 탐지 시스템의 성능을 증명하려면 대규모 트래픽과 극적인 경기 상황을 담은 실제 데이터셋이 필요하다. 제약은 다음과 같다.

1. Riot 공식 eSports API 및 B2B API(Abios 등)는 개인 개발자가 접근하기 어렵거나 비용이 든다.
2. PandaScore, Oracle's Elixir 등은 초 단위 타임라인을 제공하지 않아 실시간 검증용으로 부적합하다.
3. SOOP(아프리카TV)은 별도 API 가 없어 WebSocket 리버스 엔지니어링이 필요하고, 이는 파이프라인 구축보다 수집 기술 연구에 과도한 리소스를 요구한다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 2024 롤드컵 결승(T1 vs BLG): GOL.GG 타임라인 + YouTube 채팅(pytchat) | 최고 관심 경기로 트래픽 밀도 최적, 분/초 단위 지표, 검증된 수집 도구 | 라이브가 아닌 Replay |
| B. SOOP 리버스 엔지니어링 | 국내 플랫폼 실시간 채팅 | 수집 기술 연구에 리소스 과다 |
| C. 유료/B2B API | 공식 데이터 | 접근 불가 또는 비용 |

## 결정

**A 를 채택한다.** 인게임 지표는 GOL.GG 매치 타임라인(보간법 적용), 민심 지표는 YouTube 다시보기/중계 채팅을 `pytchat` 으로 추출·저장한다.

## 결과

- 좋아지는 것: 채팅 폭증(Velocity) 테스트에 최적이고, 복잡한 윈도우 조인 로직 검증에 적합하며, 수집 대신 가공·Flink 고도화에 집중할 수 있다. YouTube 채팅의 텍스트 노이즈 정제 역량도 보여줄 수 있다.
- 감수하는 것: Replay 방식이지만 아키텍처는 동일하므로 엔지니어링 가치는 훼손되지 않는다.
- 다시 볼 조건: 실시간 API 접근이 가능해질 때 (0017 Phase 2).
