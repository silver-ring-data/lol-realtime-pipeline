# 0009. 시계열 데이터 결합에 윈도우 기반 조인(Temporal Join)을 적용한다

> 원본: https://app.notion.com/p/3421198df8d980a4beedebf793a5246d

| | |
|---|---|
| 상태 | **채택** |
| 날짜 | 2026-04-14 |
| 결정자 | silver-ring-data |
| 관련 | 0013, 0027 |

## 배경

경기 데이터와 채팅 데이터는 발생 시점이 정확히 일치하지 않는다. 사건 발생 후 유저가 채팅을 치기까지 시간차가 있다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 전후 일정 구간(INTERVAL) 기반 윈도우 조인 | 사건과 반응 사이의 시간 간극을 흡수 | 윈도우 크기 튜닝 필요 |
| B. 타임스탬프 단순 일치 매칭 | 구현 단순 | 대부분의 반응이 매칭되지 않음 |

## 결정

**A 를 채택한다.** DB 분석 단계에서 전후 30초 INTERVAL 기반 윈도우 조인 로직을 적용한다. 구현 예: `ABS(m.game_time - e.game_time) <= 5`, `BETWEEN -interval '10s' AND +interval '20s'`.

## 결과

- 좋아지는 것: 사건(Cause)과 반응(Effect) 사이의 인과관계를 데이터로 확보한다.
- 감수하는 것: 윈도우 크기에 따라 결과가 달라진다.
- 다시 볼 조건: 실제 데이터로 윈도우 크기를 최적화할 때 (0010, 0027). 이후 Flink 전환(0013)으로 구현 위치가 DB 에서 스트림 엔진으로 옮겨졌다.
