# 0009. 시계열 데이터 결합을 위한 '윈도우 기반 조인(Temporal Join)' 적용

> 원본: https://app.notion.com/p/3421198df8d980a4beedebf793a5246d

| 상태 | 날짜 |
|---|---|
| 채택 | 2026-04-14 |

## 현상

- 경기 데이터와 채팅 데이터는 발생 시점이 정확히 일치하지 않음. (사건 발생 후 유저가 채팅을 치는 데 시간차가 발생함)

## 결정

- DB 분석 단계(Task 3)에서 단순 매칭이 아닌, **'전후 30초 INTERVAL'**을 기반으로 한 윈도우 조인 로직을 적용함.
  - **구현:** `ABS(m.game_time - e.game_time) <= 5` 및 `BETWEEN -interval '10s' AND +interval '20s'` 쿼리 활용.

## 이유

- 사건(Cause)과 반응(Effect) 사이의 시간적 간극을 기술적으로 해결하여 데이터 분석의 인과관계를 확보함.
