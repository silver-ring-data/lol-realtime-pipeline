# 0008. 하이브리드(Fact + Sentiment) 하이라이트 탐지 아키텍처를 설계한다

> 원본: https://app.notion.com/p/3421198df8d9803182b6f765a923edea

| | |
|---|---|
| 상태 | **채택** |
| 날짜 | 2026-04-14 |
| 결정자 | silver-ring-data |
| 관련 | 0006, 0007 |

## 배경

경기 지표(Metric)만으로 하이라이트를 잡으면, 수치 변화는 없지만 선수의 기술적 플레이(무빙, 스킬 회피)로 유저들이 열광하는 '비정형 명장면'을 놓칠 위험이 있다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 지표 기반 탐지(Path A) + 채팅 화력 기반 탐지(Path B) 병행 | 탐지 누락 방지, 정교함 향상 | 임계치 설정 필요 |
| B. 지표 기반 탐지만 | 단순 | 비정형 명장면 누락 |

## 결정

**A 를 채택한다.** 경기 이벤트가 없더라도 특정 시간 내 채팅 유입량이 임계치(Threshold)를 돌파하면 'SUPER_PLAY_DOUBT' 유형으로 자동 분류하여 분석 대상에 포함한다.

## 결과

- 좋아지는 것: 데이터의 침묵 속에서도 유저 반응으로 숨겨진 하이라이트를 포착한다.
- 감수하는 것: 임계치를 잘못 잡으면 오탐이 늘어난다.
- 다시 볼 조건: 실제 데이터 분포로 임계치를 재조정할 때 (0010, 0027).
