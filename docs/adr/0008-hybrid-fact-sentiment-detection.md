## 현상

- 경기 지표(Metric)만으로 하이라이트를 잡을 경우, 수치상의 변화는 없지만 선수의 기술적 플레이(무빙, 스킬 회피)로 인해 유저들이 열광하는 '비정형 명장면'을 놓칠 위험이 있음.

## 결정

- 지표 기반 탐지(Path A)와 **채팅 화력 기반 탐지(Path B)**를 병행하는 하이브리드 모델을 설계함.
  - **핵심 로직:** 경기 이벤트가 발생하지 않더라도, 특정 시간 내 채팅 유입량이 임계치(Threshold)를 돌파하면 'SUPER_PLAY_DOUBT' 유형으로 자동 분류하여 분석 대상에 포함함.

## 이유

- 데이터의 침묵 속에서도 유저의 반응(민심)을 통해 숨겨진 하이라이트를 포착함으로써 탐지 누락 방지 및 정교함 향상.
