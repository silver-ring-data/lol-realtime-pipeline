# 0006. 다각적 하이라이트 분석을 위한 데이터 소스 다변화 결정 (Chat 추가)

## 현상

- 초기 시스템 설계는 경기 데이터(골드 차이, 오브젝트 획득) 위주로 하이라이트를 추출하도록 구성됨.
- 그러나 경기 데이터만으로는 해당 장면이 실제 관람객에게 전달하는 **'심리적 임팩트'**나 **'화제성'**을 온전히 측정하기 어렵다는 한계가 발견됨.
  - **정량적 지표의 한계:** '바론 처치'라는 동일한 데이터라도, 일방적인 학살 상황인지 피 말리는 역전승의 발판인지에 따라 하이라이트로서의 가치가 다름.
  - **비정형 데이터의 부재:** 선수들의 화려한 개인기나 예상치 못한 실수 등 '수치화되지 않는' 명장면들이 하이라이트에서 누락될 위험이 있음.

## 결정

경기 지표(Fact)와 채팅 로그(Sentiment)를 **상호 보완적 소스**로 활용하여 하이라이트 판별 알고리즘을 고도화함.

- **경기 데이터의 역할:** 하이라이트 후보 지점(Candidate Point)을 탐색하는 **내비게이터**. (예: 바론, 드래곤 영혼 획득 시점)
- **채팅 데이터의 역할:** 해당 지점의 임팩트를 검증하고 가중치를 부여하는 **검증기(Validator)**. (예: 채팅 발생 빈도 및 특정 키워드 폭발 확인)
- **데이터 통합:** 분석 단계(Task 3)에서 두 소스를 Match ID와 Timestamp 기준으로 **Join**하여 최종 '하이라이트 점수'를 산출함.

## 트레이드오프

- **장점:**
  - 단순 통계 시스템을 넘어 **유저 반응 기반의 '민심 캐스터'**라는 프로젝트 고유 정체성 확립.
  - 수치에 잡히지 않는 '슈퍼 플레이' 구간을 채팅 화력 감지를 통해 추가 포착 가능.
- **단점:**
  - 텍스트 데이터의 처리 비중이 높아짐에 따라 자연어 처리(NLP) 혹은 키워드 필터링 로직에 대한 추가 연산 리소스 필요.
