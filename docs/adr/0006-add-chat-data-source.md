# 0006. 다각적 하이라이트 분석을 위해 채팅 데이터 소스를 추가한다

## 배경

초기 설계는 경기 데이터(골드 차이, 오브젝트 획득) 위주로 하이라이트를 추출했다. 그러나 경기 데이터만으로는 장면의 심리적 임팩트나 화제성을 측정하기 어렵다. 같은 '바론 처치'라도 일방적 학살인지 역전의 발판인지에 따라 가치가 다르고, 수치화되지 않는 개인기·실수 같은 명장면이 누락될 위험이 있다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 경기 지표(Fact) + 채팅 로그(Sentiment) 상호 보완 | 유저 반응 기반 '민심 캐스터' 정체성 확립, 슈퍼 플레이 구간 추가 포착 | 텍스트 처리 비중 증가로 NLP/키워드 필터링 연산 리소스 필요 |
| B. 경기 지표만 사용 | 단순 | 정량 지표의 한계, 비정형 명장면 누락 |

## 결정

**A 를 채택한다.** 경기 데이터는 하이라이트 후보 지점을 탐색하는 내비게이터, 채팅 데이터는 그 지점의 임팩트를 검증하고 가중치를 부여하는 검증기(Validator) 역할을 한다. 분석 단계에서 두 소스를 Match ID 와 Timestamp 기준으로 Join 하여 최종 하이라이트 점수를 산출한다.

## 결과

- 좋아지는 것: 단순 통계 시스템을 넘어 프로젝트 고유 정체성을 확보하고, 채팅 화력으로 숨은 명장면을 포착한다.
- 감수하는 것: 텍스트 처리 연산 리소스 증가.
- 다시 볼 조건: 채팅 데이터의 노이즈가 신호를 압도하여 검증기 역할을 못 할 때.
