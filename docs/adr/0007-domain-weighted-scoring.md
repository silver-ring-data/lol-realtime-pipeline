# 0007. 도메인 기반 하이라이트 가중치 산정 로직 채택

> 원본: https://app.notion.com/p/3421198df8d980c3a3d9f2c3a3bddcfe

| 상태 | 날짜 |
|---|---|
| 채택 | 2026-04-14 |

## 현상

- 단순히 데이터가 발생하는 것만으로는 하이라이트의 중요도를 변별할 수 없음.
- 예를 들어 '바론 처치'는 일반적인 '포탑 파괴'보다 경기 결과에 끼치는 영향력이 훨씬 큼.

## 결정

- 전문 분석 사이트인 **GOL.GG의 타임라인 데이터 구조를 벤치마킹**하여, 이벤트별 가중치 시스템(Weighted Scoring)을 도입함.
  - **로직:** 'BARON', 'ELDER_DRAGON', 'ACE' 등 핵심 이벤트에 대해 `is_major` 플래그를 자동 부여하고, 채팅 카운트에 따른 추가 가중치를 합산하여 `impact_score`를 산출함.

## 이유

- 수천 개의 데이터 중 실제 대시보드나 편집에 우선적으로 쓰여야 할 '진짜 명장면'을 시스템이 스스로 판단할 수 있게 됨.
