# 0037. 서빙용 채팅 선별 키워드를 정한다

|---|---|
| 상태 | **채택** |

| 결정자 | silver-ring-data |

## 배경

0031 의 4단계 선별 기준을 실제 채팅 로그에 적용하기 위해, 특정 선수나 팀에 치우치지 않고 범용적으로 쓸 수 있는 선별 키워드·패턴이 필요했다. (노션 원문의 배경·이유 항목은 비어 있다.)

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 단계별 범용 키워드 가이드 | 특정 팀·선수에 치우치지 않음 | 신조어 갱신 필요 |

## 결정

**A 를 채택한다.** 단계별 키워드 가이드는 다음과 같다.

- 1단계 완전 배제: 시스템 봇 계정(`@nightbot`), `/` 로 시작하는 플랫폼 명령어(`/명령어`, `/집중모드`, `/구독자전용모드`, `/빠른재생`, `/fast` 등), 스팸 방지 고정 멘트(`[stop spamming words/phrases]`, `[warning]`, `Not on my watch!`, `I hope you learned your lesson.` 등)
- 2단계 안전성 확보: 비하성 접미사·접두사(`~까`, `~빠`, `~갈`, `~따운`, `~딱` 등 특정 팀 비하로 확장되는 단어), 혐오·공격적 표현(`개패자`, `조졌다`, `쓰레기`, `폐기물`, `배신자`, `쪽팔린다`, `수치스럽다`, `망신`), 자음 위주 비속어 변형(`ㅆㅂ`, `ㅆㄱㅈ` 등)
- 3단계 시각적 최적화: 허용 감탄사(`ㅋㅋ`, `ㅎㅎ`, `ㄷㄷ`, `ㅠㅠ`, `ㅜㅜ`, `??`, `!!`, `캬`, `와`); 요약·이모지 변환 대상은 동일 단어 3회 이상 반복, 이모지만 나열된 특수문자 도배, 30자 이상의 개인적 감상·훈수
- 4단계 맥락 기반 노출 (우선 노출 키워드):

| 카테고리 | 우선 노출 키워드 (범용) |
|---|---|
| 경기 흐름 | `역전`, `우승`, `나이스(ㄴㅇㅅ)`, `가즈아`, `할만하다`, `이겼다`, `졌다(ㅈㅈ/gg)`, `비상` |
| 교전/한타 | `한타`, `솔킬`, `크랙`, `슈퍼플레이`, `이니시`, `포커싱`, `에이스` |
| 게임 요소 | `밴픽(벤픽)`, `조합`, `오브젝트`, `용`, `유충`, `전령`, `바론`, `퍼블`, `다이브`, `스왑`, `텔(텔포)` |
| 성장 상태 | `밸류`, `골드차이`, `성장`, `템(아이템)`, `CS`, `렙(레벨)` |

## 결과

- 좋아지는 것: 0031 의 기준을 실제 필터 로직으로 구현할 수 있다.
- 감수하는 것: 키워드 목록은 주기적 갱신이 필요하다.
- 다시 볼 조건: 다른 종목이나 플랫폼에 적용할 때.
