# 0020. S3 Bronze 에 무필터링 원본(Raw Data)을 100% 보존한다

> 원본: https://app.notion.com/p/34a1198df8d98042afebd499e5022c76

| | |
|---|---|
| 상태 | **채택** |
| 날짜 | 2026-04-22 |
| 결정자 | silver-ring-data |
| 관련 | 0019, 0026 |

## 배경

수집된 채팅 중 욕설 등 쓸모없는 데이터를 S3 적재 전에 필터링할 것인지 결정해야 했다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. Bronze 에 원본 그대로(Immutable) 저장, 필터링은 Flink 에서 수행 | 단일 진실 공급원(SSOT) 확보, 향후 피처 확장성 | 저장 용량 증가 |
| B. 적재 전 필터링 | 저장 용량 절감 | 원본 맥락 유실, 재처리 불가 |

## 결정

**A 를 채택한다.** S3 Bronze Layer 에는 한 글자의 훼손도 없이 원본 그대로 저장한다.

## 결과

- 좋아지는 것: 데이터 레이크의 제1원칙인 단일 진실 공급원을 확보하고, 추후 'AI 기반 악성 채팅 탐지 모델' 같은 피처 개발 시 원본 대화 맥락을 활용할 수 있다.
- 감수하는 것: 저장 용량.
- 다시 볼 조건: 저장 비용이 유의미하게 커질 때 (Lifecycle Policy 로 대응).
