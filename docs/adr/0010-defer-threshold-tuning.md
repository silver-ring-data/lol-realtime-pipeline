## 배경

하이라이트 판별용 시간 윈도우(15~30초)와 채팅 빈도 임계치는 현재 임의로 설정되어 있다. 실제 서비스 환경에서는 영상 송출 지연과 유저 반응 속도에 따라 이 수치가 달라질 수 있다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 실제 플랫폼 API 연동 후 확보한 데이터로 최적화 | 실제 분포 기반의 정확한 평균·표준편차 확보 | 최적화 시점이 늦어짐 |
| B. 지금 임의 수치로 확정 | 빠름 | 근거 없는 수치 |

## 결정

**A 를 채택한다.** 실시간 API 연동 후 약 10경기 이상의 샘플 데이터를 수집하여 통계적으로 윈도우 크기를 재조정(Fine-tuning)한다.

## 결과

- 좋아지는 것: 하이라이트 누락 없는 최적의 선을 실제 데이터로 찾는다.
- 감수하는 것: 그때까지는 임의 수치를 사용한다.
- 다시 볼 조건: 실제 데이터셋이 확보될 때. (0027 에서 2024 롤드컵 결승 데이터 기반으로 파라미터를 결정했다.)
