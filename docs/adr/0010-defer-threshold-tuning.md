# 0010. 데이터 기반 임계치 및 윈도우 최적화 보류 결정

> 원본: https://app.notion.com/p/3421198df8d980e089ebe1232a2a87e9

| 상태 | 날짜 |
|---|---|
| 보류 | 2026-04-14 |

## 현상

- 현재 하이라이트 판별을 위한 시간 윈도우(15~30초)와 채팅 빈도 임계치는 임의로 설정되어 있음.
- 실제 서비스 환경에서는 영상 송출 지연(Latency)과 유저 반응 속도에 따라 이 수치가 달라질 수 있음.

## 결정

- 구체적인 수치 최적화는 **실제 플랫폼(유튜브/치지직 등) API 연동 이후 확보된 실제 데이터셋을 바탕으로 수행**하기로 함.
  - 실시간 API 연동 후 약 10경기 이상의 샘플 데이터를 수집하여 통계적으로 윈도우 크기를 재조정(Fine-tuning)할 예정.

## 이유

- **데이터 정합성:** 실제 데이터의 분포(Distribution)를 확인해야 정확한 평균값과 표준편차를 구할 수 있음.
- **효율적 리소스 관리:** 무조건 짧게 잡기보다 실제 하이라이트 누락이 없는 최적의 선을 찾는 것이 중요함.
